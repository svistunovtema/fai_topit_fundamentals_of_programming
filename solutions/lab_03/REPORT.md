### Дополнительный алгоритмический эксперимент
```python
number = int(input())
is_prime = number >= 2
divisor = 2

while is_prime and divisor * divisor <= number:
    if number % divisor == 0:
        is_prime = False
    divisor += 1

if is_prime:
    print("Простое число")
else:
    print("Не простое число")
```
Это проверка простое ли число. is_prime хранит результат проверки. Для 1 он сразу равен False. Для чисел от 2 программа перебирает возможные делители, пока divisor * divisor <= number. Если остаток от деления равен нулю, найден делитель и цикл прекращается при следующей проверке условия.

#### Сложность алгоритмов
Таблица 2 - сложность алгоритмов
| Алгоритм | Временная сложность | От чего зависит число операций | Дополнительная память |
| --- | --- | --- | --- |
| Сумма, минимум, максимум и подсчёт чётных | `O(n)` | Для каждого элемента выполняется фиксированное число операций | `O(1)` для суммы, минимума, максимума и счётчика |
| Подсчёт значений выше среднего | `O(n)` | Каждый элемент один раз сравнивается со средним | `O(1)` для среднего и счётчика |
| Линейный поиск первого вхождения | `O(n)` в худшем случае | Поиск заканчивается при первом совпадении. Если совпадений нет, проверяются все элементы | `O(1)` для искомого числа, текущего индекса и результата |
| Проверка простоты | `O(√m)` в худшем случае | Для простого числа проверяются все возможные делители от 2 до `√m` включительно | `O(1)` для числа, текущего делителя и результата проверки |

`n` — длина списка, `m` — число, которое проверяется на простоту.


Почему достаточно квадратного корня

Если число m составное, его можно записать как m = a * b, где оба множителя больше единицы. Если бы оба множителя были больше √m, их произведение было бы больше m. Значит, хотя бы один делитель обязательно находится в диапазоне от 2 до √m. Верхняя граница включается, чтобы обнаружить, например, делитель 7 у числа 49.

### Объяснение
Множество хранит уникальные элементы. Если имя студента или идентификатор
работы встречается повторно, вызов `add()` сохраняет его в одном экземпляре.
Пересечение `&` даёт студентов, которые есть в множествах обеих работ.

Кортеж `(student, laboratory)` можно использовать как ключ словаря, потому
что обе его строки хешируемы, а сам кортеж неизменяем. Список изменяем и
нехешируем, поэтому его нельзя использовать как ключ.

Для частого поиска лучшего результата удобно использовать словарь.
По ключу `(student, laboratory)` результат находится в среднем за `O(1)`.
При хранении результатов в списке поиск нужной пары может потребовать
просмотра всех `n` записей.

Таблица 3 -оценка средней сложности добавления и поиска для использованных коллекций
| Коллекция | Добавление | Поиск |
| --- | --- | --- |
| Список `list` | `O(1)` амортизированно при добавлении в конец через `append()` | `O(n)` в среднем при поиске по значению |
| Множество `set` | `O(1)` в среднем через `add()` | `O(1)` в среднем при проверке принадлежности через `in` |
| Словарь `dict` | `O(1)` в среднем при добавлении или обновлении по ключу | `O(1)` в среднем при поиске по ключу |

`n` — число элементов в коллекции. Амортизированная оценка означает,
что отдельный `append()` может занять больше времени при расширении
списка, но средняя стоимость операции в серии добавлений равна `O(1)`.

### Исследование LEGB
Python ищет имя от ближайшей области видимости к самой общей.

```text
L — локальная область вложенной функции change_course
    new_course
    |
E — объемлющая область функции demonstrate_scope
    course, change_course
    |
G — глобальная область файла task_4.py
    course, demonstrate_scope
    |
B — встроенные имена Python
    print
```

- `new_course` внутри `change_course()` находится в локальной области `L`.
  Это параметр, которому при вызове передаётся строка `"Функции"`.
- `course` внутри `change_course()` относится к области `E`. Объявление
  `nonlocal course` указывает, что присваивание `course = new_course`
  меняет переменную внешней функции.
- `course` и `change_course` внутри `demonstrate_scope()` находятся в
  локальной области самой `demonstrate_scope()`. Буква `L` обозначает
  локальную область той функции, в которой выполняется строка кода.
- `demonstrate_scope` и `course` при обращении на уровне файла находятся
  в глобальной области `G`. Глобальная переменная `course` сохраняет
  значение `"Основы программирования"`.
- `print` внутри `demonstrate_scope()` Python ищет в её локальной области,
  затем в глобальной области и находит среди встроенных имён `B`.
  На уровне файла поиск `print` идёт из глобальной области к встроенной.

| Обычная группа | Данные из задания | Лидер — Дарья, среднее группы 79.38, минимум 55, максимум 97, по одному студенту в каждой из четырёх категорий | Совпало |
| Один студент | Анна `[80, 90]` | Среднее группы 85 | 85.0 |
| Несколько лидеров | Анна `[80, 90]`, Борис `[85]` | Лидеры — Анна и Борис | `['Анна', 'Борис']` |
| Пустая группа | `{}` | Среднее `None`, список лидеров пуст | `None`, `[]` |
| Студент без результатов | Илья `[]` | Среднее, минимум и максимум равны `None`. Статус «нет результатов», счётчик этого статуса равен 1 | Совпало |
| Границы категорий | `0, 59, 60, 74, 75, 89, 90, 100` | `0, 59` — недостаточный. `60, 74` — удовлетворительный. `75, 89` — хороший. `90, 100` — отличный | Совпало |

### Декомпозиция и сложность

`mean()`, `minimum()` и `maximum()` выполняют отдельные числовые операции.
`student_summary()` собирает статистику одного студента и определяет его
категорию. `group_summary()` считает показатели группы, а
`find_top_students()` находит всех лидеров. `format_report()` сортирует
готовые итоги и превращает их в текст.

Пусть `n` — количество студентов, а `m` — общее количество оценок.
Построение общей статистики занимает `O(n + m)` времени. Программа
перебирает студентов и проходит по оценкам фиксированное число раз.
Дополнительная память для общей статистики составляет `O(n + m)` в
худшем случае. Список всех оценок занимает `O(m)`, а список лидеров
может содержать до `n` имён.

Сортировка рейтинга выполняется при форматировании отчёта и занимает
до `O(n log n)` времени.
